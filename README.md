# استوديو يُتبع... | Yotba Studio 🎙️

لوحة التحكم والإدارة المركزية واستوديو الإنتاج لمنصة المسلسلات الصوتية الأصلية **يُتبع...**

## المميزات
- **استوديو المسلسلات والمواسم والحلقات**: واجهة بصرية موحدة لإدارة الأعمال الدرامية وفصولها ورفع الملفات الصوتية.
- **محرر النصوص والتفريغ الصوتي (Transcripts)**: مزامنة دقيقة للنصوص التزامنية مع أوقات التشغيل.
- **إدارة المستمعين والاشتراكات (Entitlements)**: متابعة المستخدمين وصلاحيات الوصول والاشتراكات.
- **إدارة المحتوى الترويجي والواجهة الرئيسية (Homepage Sections)**: تحكم كامل في تصنيفات وأقسام المنصة.
- **إدارة البلاغات والتعليقات (Moderation)**: مراجعة التعليقات وحظر المحتوى المخالف.
- **تخزين سحابي فائق السرعة عبر Cloudflare R2**: رفع مباشر للملفات الصوتية والغلاف بجودة سينمائية فائقة.
- **قاعدة بيانات سحابية موحدة عبر MongoDB Atlas**: مزامنة لحظية مع المنصة العامة (`https://yotba.vercel.app`).

## تشغيل لوحة التحكم محليًا

1. اسحب أحدث كود من المستودع، بعد حفظ أي تعديلات محلية لدى الفريق.
2. ضع ملف `.env.local` المعتمد من صاحب المشروع بجانب `package.json`. الملف لا ينتقل مع Git لأنه يحتوي على أسرار. تسجيل الدخول يحتاج `MONGODB_URI` لقاعدة البيانات التي تحتوي على حسابات الفريق، و`JWT_SECRET` صالحًا. إعدادات R2 لازمة لرفع الملفات وليست للتحقق من كلمة المرور.
3. نفّذ `npm ci` ثم `npm run dev` وافتح `http://localhost:3001/login`.
4. سجّل بحساب فريق الاستوديو النشط، وليس بحساب مستمع. وجود ملف البيئة وحده لا يمنح حسابًا صلاحيات إدارية.

إذا ظهر في سجل السيرفر `querySrv ECONNREFUSED`، أنشئ ملف `.env.development.local` بجانب `package.json` وأضف:

```dotenv
MONGODB_DNS_SERVERS=1.1.1.1,8.8.8.8
```

أوقف `npm run dev` بـ `Ctrl+C` وشغله مجددًا. هذا إعداد اختياري للشبكات التي تفشل فيها استعلامات DNS الخاصة بـ MongoDB Atlas، ويعمل في التطوير فقط داخل عملية Node، ولا يغير DNS ويندوز أو إعدادات فيرسال. لا يلزم إذا كان الاتصال يعمل بالفعل. القيم عناوين IP لخوادم DNS مفصولة بفواصل؛ يلزم إعادة تشغيل السيرفر عند تغييرها.

لو استمر الفشل، افحص رسالة السيرفر: مهلة الاتصال قد ترتبط بالشبكة أو بقائمة السماح لعنوان IP الحالي في Atlas، أما رسالة بيانات الدخول غير الصحيحة بعد نجاح الاتصال فتحتاج مراجعة الحساب وكلمة المرور. لا تفتح قاعدة البيانات لكل عناوين الإنترنت لمجرد حل مشكلة جهاز واحد.

شارك ملفات البيئة مع أعضاء الفريق المعتمدين عبر قناة خاصة، ولا ترفعها إلى GitHub. إذا كانت `MONGODB_URI` تشير إلى قاعدة الإنتاج، فأي تعديل محتوى محلي سيغيّر بيانات الموقع الحقيقي أيضًا.
